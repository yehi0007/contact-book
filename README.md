# Contact Book

A single-page Contact Book web application created using Vue 3, Vue Router 4, Vite, Bootstrap, and localStorage.

## Features

- View all contacts
- Sort contacts alphabetically by last name
- Search contacts by first or last name
- Add new contacts
- View contact details
- Edit existing contacts
- Delete contacts
- Store contact information using localStorage
- Navigate between application views using Vue Router

## Technologies Used

- Vue 3
- Vue Router 4
- Vite
- JavaScript
- Bootstrap
- localStorage

## Running the Project

Install the dependencies:
npm install

Start the development server:
npm run dev
